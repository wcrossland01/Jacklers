This page is private to you. To publish, it needs permission to save files in your GitHub repository. You do this once per device.

  1. Open GitHub's token page.
  2. Name it Jacklers editor and set an expiry (90 days is sensible).
  3. Under Repository access, choose Only select repositories and pick Jacklers.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.

The token is stored only in this browser. Never share it or paste it into a chat. Use a private computer, and press Sign out on shared ones.
